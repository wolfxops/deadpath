Deadpath
unused code · false positives

Dead code and live code
look the same to an agent.

A route, a bean, a cron job, a feature flag. Naive scanners call them unused. Agents then delete them — or rewrite around them forever.

False positives

Django signals, FastAPI routes, Spring beans, Rails models, and Flutter widgets are loaded by the framework, not by an import.

Every cleanup session re-crawls the tree and re-reads the same files. That rediscovery is the largest token sink in agent cleanup.
